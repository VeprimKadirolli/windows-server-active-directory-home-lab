# Windows Server 2022 – Active Directory Home Lab

## Présentation du projet

Ce projet consiste à concevoir, déployer et administrer un environnement de laboratoire informatique (Home Lab) basé sur Windows Server 2022 et Active Directory.

L'objectif est de mettre en pratique les connaissances en administration systèmes, gestion des identités, configuration réseau et sécurisation d'un environnement Windows.

## Environnement technique

- **Hyperviseur :** VMware Workstation Pro
- **Serveur :** Windows Server 2022 Standard Evaluation
- **Client :** Windows 11 Pro
- **Services :** Active Directory Domain Services (AD DS), DNS
- **Domaine :** IT3NET.com

## Travaux réalisés

- Installation et configuration de Windows Server 2022.
- Promotion du serveur en contrôleur de domaine.
- Installation et configuration du service DNS.
- Intégration d'un poste Windows 11 au domaine.
- Création et organisation des unités organisationnelles (OU).
- Gestion des utilisateurs, groupes et comptes privilégiés.
- Délégation des tâches administratives.
- Configuration et application de stratégies de groupe (GPO).
- Gestion et restauration d'objets avec la corbeille Active Directory.

## Documentation

Le dépôt contient la documentation technique du laboratoire, les captures d'écran des configurations et les différentes étapes de réalisation.

## Améliorations envisagées

- Déploiement de postes clients supplémentaires.
- Mise en place du service DHCP.
- Automatisation de tâches avec PowerShell.
- Approfondissement des stratégies de sécurité Active Directory.
